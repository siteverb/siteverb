# Siteverb

Siteverb is open-source release infrastructure for WebMCP. It helps teams create customer-owned
browser tools, define complete user journeys as portable contracts, and prove those journeys through
source coverage and deterministic real-browser checks.

**Create. Prove. Improve.**

- Native-first WebMCP SDK
- Portable journey contracts
- Source-to-contract audit
- Real-browser runner
- Customer-owned GitHub Action
- Local coding-agent migration skill

Start with the [`siteverb`](https://github.com/siteverb/siteverb) repository.
